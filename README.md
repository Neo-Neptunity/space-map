# 容量マップ

フォルダの中身を、大きさに比例した四角で敷き詰めて見せます（ツリーマップ）。何が容量を食っているかが一目でわかります。そのまま開く・ごみ箱へ送ることもできます。ごみ箱へ送るときは、本体が確認します。通信はしません。

[explorer_plus](https://github.com/Neptunity-git/explorer_plus) の MOD です。`neo.space-map` 1.0.0。

フォルダの大きさの計算は重いので、大きなフォルダでは少し時間がかかります。計算が終わっていないフォルダは、あとから大きさが入ります。

## 使いかた

| 操作 | 動き |
|---|---|
| クリック | 選ぶ。Ctrl を押しながらで、複数 |
| ダブルクリック | 開く |
| 右クリック | メニュー |
| Delete | ごみ箱へ。本体が確認する |
| Backspace | 上の階層へ |

- 上の「種類で色分け」と「古さで色分け」で、色の分けかたを切りかえます。
- 色の凡例を押すと、その種類だけが目立ちます。
- 四角の数が多いときは、小さいものを「その他」にまとめます。

## 入れ方

1. [Releases](https://github.com/Neo-Neptunity/space-map/releases) を開き、いちばん新しい版の zip（`neo.space-map-版.zip`）をダウンロードします。「Source code」ではなく、自分で付けた zip のほうです。
2. explorer_plus のホームの「MOD」の欄で「＋ MOD を入れる（zip）」を押して、zip を選びます。解凍はしません。
3. 確認の画面の「このビューが使う情報」を読んで、よければ入れます。

## 使う情報

| 使う情報 | 使いみち |
|---|---|
| `entries` | フォルダの中身を、四角にする |
| `size` | ファイルの大きさ |
| `folderSize` | フォルダの中身の合計の大きさ。重いので、後から少しずつ届く |
| `modified` | 更新日時。「古さで色分け」に使う |
| `icons` | Windows のアイコンを出す |

## 設定

描く四角の最大数（20〜800。標準は 250。残りは「その他」にまとめる）・隠しファイルも含める。
